# Сканворды — PWA для iPad

Сканворды на русском и украинском языках. Работает без сервера и без сети: сканворды
составляются прямо на устройстве из встроенного словаря, прогресс хранится в `localStorage`.

## Установка на iPad
1. Опубликуйте папку на GitHub Pages (см. ниже).
2. Откройте адрес в Safari → «Поделиться» → «На экран „Домой“».
3. Дальше приложение запускается с иконки и работает офлайн.

## Публикация на GitHub Pages
```bash
git init && git add . && git commit -m "Сканворды 1.0.0"
git remote add origin git@github.com:<you>/skanword.git
git push -u origin main
```
В репозитории: Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
Сборка не нужна: это чистые статические файлы.

## Выпуск новой версии
```bash
node tools/bump-version.mjs 1.1.0 "Что нового" "Що нового"
git commit -am "1.1.0" && git push
```
Скрипт меняет версию в трёх местах: `version.json`, `js/version.js` и `sw.js`.
Приложение проверяет `version.json` не чаще раза в сутки (при запуске и при возвращении в приложение)
и показывает баннер «Доступна версия X — Обновить / Позже». После «Обновить» новый Service Worker
активируется, страница перезагружается, прогресс сохраняется. В настройках есть ручная проверка.

Если меняется формат данных в `localStorage`, увеличьте `SCHEMA` в `js/storage.js`
и добавьте функцию в `MIGRATIONS`.

## Словари
Исходники лежат в `dict/src/<lang>*.txt`, формат строки: `слово|определение|уровень`,
где уровень 1 — лёгкое слово, 2 — среднее, 3 — редкое.
После правок выполните:
```bash
node tools/build-dict.mjs        # собирает dict/ru.txt и dict/uk.txt, проверяет алфавит, дубли, длину и утечку ответа в определение
node tools/build-fallback.mjs    # пересобирает запасные сканворды
node tools/test-generator.mjs 50 # стресс-тест генератора
```
Ё приравнивается к Е, апостроф в украинских словах не пишется в клетки.

## Устройство
| Файл | Что делает |
|---|---|
| `js/generator.js` | генератор: жадная укладка + локальный поиск, жёсткие лимиты шагов и времени, до 5 попыток, `verify()` |
| `js/gen-worker.js` | генерация в Web Worker; при неудаче отдаёт запасной сканворд |
| `js/storage.js` | фиксированные ключи `scw:*`, схема и миграции, история (5 на язык + текущий), квота, уборка |
| `js/update.js` | ежедневная проверка версии и применение обновления |
| `js/app.js` | интерфейс: сетка с зумом, клавиатуры, подсказки, таймер, история, статистика, настройки |
| `sw.js` | офлайн-кэш; старые кэши удаляются при активации |

### Защита от зацикливания
- каждое уложенное слово добавляет хотя бы одну новую клетку, поэтому слов не больше, чем клеток;
- лимит шагов перебора и бюджет времени на попытку, общий бюджет около 3,5 с;
- в основном потоке сторожевой таймер на 10 с: зависший воркер останавливается, затем повтор;
- в крайнем случае открывается один из запасных сканвордов.

### localStorage
Только ключи `scw:meta`, `scw:settings`, `scw:stats`, `scw:games:{ru,uk}`, `scw:used:{ru,uk}`.
Чужие ключи с префиксом `scw:` удаляются при запуске, битый JSON сбрасывает только свой ключ.
При переполнении сначала урезается список недавних слов, затем история.
Типичный объём — 20–60 КБ.

## Управление
- Нажатие на клетку выбирает её, повторное нажатие меняет направление. Нажатие на вопрос выбирает его слово.
- Физическая клавиатура: буквы (работает и при латинской раскладке), стрелки, Backspace, Tab/Enter — следующее слово, пробел — смена направления.
- Зум — щипком двумя пальцами.
